Test-only change: the 2FA challenge completion handler
(`internal/api/handlers_auth_2fa.go`, `VerifyTOTPLogin`) had three failure
paths no test reached — a genuine storage fault while consuming the TOTP
step (as opposed to a replay), a session that cannot be issued for the
account, and a provider-logout relocation that fails after the session was
already minted. The first two now answer with the internal-error spec and
mint no session; the third tears the minted session down again instead of
leaving a signed-in owner whose provider logout integration was dropped.

The new tests live in `internal/api/handlers_auth_2fa_failure_paths_test.go`
and drive the real handler over HTTP against the shared SQLite test
database; the fault injection is confined to the repository and store
interfaces the services already depend on. The shared app helper gained two
service-override options, matching the existing `dayService` option, so no
production wiring changed.
